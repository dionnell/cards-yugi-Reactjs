# Cartas Yugi

pagina catalogo de cartas
contiene un navbar, un buscador, filtros de categorias, un efecto de flip para las cartas y un paginador

las tecnologias usadas son:
- react-modal
- react-router-dom
- reactjs-flip-card
- query-string
- fetch para consumir la Api


  https://react-yugi-cards.netlify.app/
