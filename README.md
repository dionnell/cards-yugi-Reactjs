# Cartas Yugi

Esta aplicación web permite explorar y buscar cartas del universo de Yu-Gi-Oh! de manera interactiva.

## Funcionalidades

- **Listado de cartas:** Visualiza una galería de cartas de Yu-Gi-Oh! con imágenes y detalles.
- **Búsqueda de cartas:** Permite buscar cartas por nombre o atributos específicos.
- **Filtrado:** Filtra cartas por tipo, atributo u otras características.
- **Vista detallada:** Consulta información detallada de cada carta seleccionada.
- **Interfaz moderna:** Diseño visual atractivo y responsivo.

## Tecnologías utilizadas

- ReactJS
- Consumo de API de cartas Yu-Gi-Oh!
- CSS Modules o TailwindCSS (según implementación)
- Despliegue en Netlify
